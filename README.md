# وَرّاق — من نص إلى كتاب

أداة تحوّل نص كتاب مكتوب بصيغة Markdown مبسّطة إلى كتاب منسّق، بعدة تنسيقات جاهزة (ألوان وخطوط مختلفة)، قابلة للتصدير كملف PDF مباشرة من المتصفح.

## التشغيل محلياً

    npm install
    npm run dev

## البناء للإنتاج

    npm run build
    npm run preview

## صيغة النص

راجع زر "صيغة النص" داخل التطبيق، أو ملخص سريع:

    ---
    title: عنوان الكتاب
    subtitle: العنوان الفرعي
    ---

    # فصل رئيسي

    نص الفقرة العادية.

    ## عنوان فرعي مرقّم

    المصطلح: يُبرَز الجزء الذي قبل النقطتين تلقائياً.

    > السطر الأول من بيت الشعر
    > السطر الثاني من بيت الشعر

## التنسيقات المتاحة

- **زمردي — نسخ**: أخضر/عنّابي، بخط Noto Naskh Arabic
- **شهرزاد — كلاسيكي**: أخضر مزرقّ/بنّي، بخط Scheherazade New
- **عتيق — أميري**: بنّي/عنّابي، بخط Amiri
- **حديث — بدون تشكيل**: كحلي/برتقالي، بخط Noto Sans Arabic

## تطبيق ويب تقدّمي (PWA) — يعمل دون اتصال

المشروع يستخدم `vite-plugin-pwa` لتوليد service worker يخزّن مسبقاً كل ملفات
التطبيق (JS وCSS وحتى الأجزاء التي تُحمَّل عند الحاجة مثل محرّر الأكواد وPDF/DOCX
وEPUB) عند أول زيارة. بعدها يعمل التطبيق بالكامل دون إنترنت — تم التحقق من ذلك
فعلياً بقطع الشبكة وإعادة تحميل الصفحة من الصفر.

عند نشره على أي استضافة (Vercel، Netlify، GitHub Pages)، يمكن تثبيته من
المتصفح كتطبيق مستقل.
